# Um cantinho para o Pietro 💜

Site romântico estático, responsivo e sem banco de dados. Feito com HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Não precisa instalar nada.

## Personalizar as fotos
Coloque quatro imagens suas na pasta `assets/fotos/` com estes nomes:
- `foto-1.jpg`
- `foto-2.jpg`
- `foto-3.jpg`
- `foto-4.jpg`

Se suas fotos forem PNG ou WEBP, altere também a extensão nos caminhos dentro de `index.html`.

## Personalizar a cartinha
Abra `index.html` e procure por `Meu querido Pietro` para editar o texto da carta.

## Música (opcional)
Coloque um arquivo de áudio seu chamado `musica.mp3` dentro de `assets/`. O botão de música já está no site. Use uma música que você tenha direito de utilizar.

## Contador
O contador já está configurado para 29 de janeiro de 2026, à meia-noite no horário local do navegador. Para alterar, edite `startDate` em `script.js`.

## Publicar gratuitamente
Você pode publicar a pasta em serviços de hospedagem estática como GitHub Pages, Netlify ou Cloudflare Pages. Para GitHub Pages, envie os arquivos do projeto para um repositório e habilite Pages nas configurações.

## Observação
O site não coleta nem envia dados. As fotos e a música ficam nos próprios arquivos do site. Para compartilhar com o Pietro, publique o projeto e envie o link gerado pela hospedagem.
